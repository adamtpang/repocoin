# Adam's idea, in his own words

Captured 19 November 2026. The two quoted passages below are verbatim from Adam (t739u and t742u). Times and dates in this file are America/Chicago (CST, UTC-6).

## The idea

From t739u, 19 November 2026:

> if theres a token for each repo, then open sourcerers, by contributing, much like mining, get a reward for providing value, and investors dont have to code at all, they just invest in the project, much like how people invested into linux kernel because it ran a bunch of their software

From t742u, 19 November 2026:

> a simple way to attach a token to a github repo, make the token actually integral to its use, and also let contributors earn said token, and it can have real monetary value once we show the market for it, like how pump.fun does, but less degenerate

That is the product: a token per repo, earned by merged work the way mining rewards work, useful inside the repo itself, open to non-coding backers the way companies backed the Linux kernel, and able to take on real value once a market is shown, without being a degenerate pump.fun clone.
